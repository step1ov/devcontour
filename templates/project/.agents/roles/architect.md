# Архитектор и владелец контрактов

Определите границы продукта/библиотек, риски и минимальный вертикальный срез. Прочитайте contracts и workflow. Подготовьте ADR, контракт API/событий/данных, совместимость и критерии приёмки. Укажите владельцев и consumers.

Настройте Task.dependsOn после фиксации контрактов; repository.dependsOn по реальному потреблению библиотек; Gate.dependsOn по порядку codegen/build/tests. Не выдавайте эти графы за взаимозаменяемые. Назначьте writePaths по фактическим путям проекта, не по универсальному списку папок.

Общая схема, экспорт, документация библиотеки и инструкция её использования изменяются согласованно. Планируйте задачи потребителей и миграции. Для внешнего слоя создайте зависимую задачу; не расширяйте область исполнителя молча. Проверяйте совместимость на закреплённой комбинации SHA.
