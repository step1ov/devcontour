# Мобильная проверка: Maestro

Этот пакет подключается только мобильным задачам через contextPacks. MCP-настройка сама по себе не устанавливает Maestro, не собирает приложение и не доказывает проверку.

1. Ведущий агент проверяет инструменты, выбирает реальное устройство по list_devices и регистрирует его ID как resource kind=device. Настраивает QA-сборку, backend и автоматическую авторизацию/seed в изолированной тестовой среде. Production-аутентификацию не ослаблять.
2. Подготовка сборки → установка → readiness и подготовка данных → сценарий → отчёт → cleanup. Записывайте SHA исходников, идентификатор/хеш сборки, платформу и устройство. Нельзя тестировать старую установленную сборку и приписывать результат новому SHA.
3. Читайте исходник экрана и актуальную hierarchy/inspect_screen; не угадывайте ID устройства или селектор. После перехода перечитайте дерево. Для элементов без устойчивого текста запросите testID/accessibilityLabel у владельца приложения отдельной зависимой задачей.
4. Проверяйте сохранение и повторное чтение данных, ошибки сервера и доступность. Успешный tap сам по себе ничего не доказывает. Не завязывайте общий сценарий на координаты или порядок элементов без необходимости.
5. Общие вход/подготовку/очистку выделяйте в параметризованные subflows; проверяйте обязательные переменные. Сценарий не зависит от порядка запуска других тестов. Cleanup выполняйте также после ошибки.
6. MCP и CLI используют устройство последовательно. Runner резервирует устройство на весь запуск; другие workspace с тем же kind/value ждут. Даже внутри одного запуска не стартуйте два драйвера одновременно.
7. Сохраняйте воспроизводимый flow, JUnit и скриншоты/логи падения. Обёртка сохраняет ненулевой exit code, даже если отчёт собрался. Проверьте команды и lifecycle hooks по версии установленного Maestro; особенности iOS не считайте автоматически действующими на Android.

Если автономная тестовая авторизация недоступна, ведущий агент фиксирует блокер и необходимое действие. Не имитируйте пройденный вход сохранённой чужой сессией или отключением проверок.
