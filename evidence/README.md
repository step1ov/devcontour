# Артефакты проверок

Исторические результаты перенесены из документации без изменения статусов проверок. В публикуемых копиях личные пути заменены на `<home>`, `<checkout>` и `<tmp>`. Это обезличенные журналы, а не побайтовые оригиналы. Исходная история изменений сохраняется в Git.

Каталог не входит в npm-пакет. Новые полные логи следует сохранять как артефакты CI; в Git достаточно итогов и небольших обезличенных свидетельств, необходимых для разбора.
