Дата: 18 сентября 2026 года. Среда: macOS, Node.js 24.3.0. Проверки используют временные Git-репозитории, worktrees и независимые clones. Вызовы платных моделей, push и публикация не выполнялись.

## Состав изменения

- Профиль INTENT.md v1: цель, пользователи, ограничения, nonGoals, предположения, истории и критерии по релизам; закреплённые ссылки на подробные REQ и обоснованные исключения.
- Детерминированный генератор и проверка соответствия структурного блока Markdown-представлению. Генератор возвращает текст без записи в проект.
- Производный отчёт полноты, включая истории без задач, новые нераспределённые REQ, изменившиеся исключения и отсутствующие источники.
- Обычные Task.requirements, review и SHA evidence для историй; корректировки сохраняют прежние принятые ревизии.
- Общая карта workspace с закреплёнными ссылками на релизы компонентов. Подробности историй, задач и ТЗ остаются у компонентов.
- CLI/HTTP/MCP, skill, инструкции ведущего агента и двенадцатое руководство, переносимое setup.

## Что именно подтверждено

Тест формата проверяет устойчивые IDs, неизвестные ссылки, дубликаты, владельца, недопустимые пути и symlink. Текст критериев не может незаметно добавить REQ-секции. Правка только Markdown-представления отклоняется. Генерация не меняет файл пользователя.

Тест инвентаря начинает с пустого графа, обнаруживает неразложенную историю, отличает будущий релиз и явные исключения. Незакоммиченная правка источника не меняет committed snapshot; новый REQ, изменившееся исключение и исчезнувший файл не дают ложного полного покрытия.

Git fixture запускает автора и двух reviewers через обычный scheduler. Все три получают продуктовые ограничения и закреплённую историю; задача проходит candidate/integration проверки. Изменение критерия после приёмки сбрасывает актуальность покрытия. requirements-correct и повторная реализация восстанавливают его, сохраняя digest прежней принятой ревизии. Удаление test evidence снова делает отчёт неполным. Дополнительная незавершённая задача с подробным REQ без привязки к истории также обнаруживается рядом с уже выполненной задачей.

Проверка workspace использует отдельные репозитории приложения и библиотеки. Общий отчёт содержит ссылки и числа, без текстов критериев и taskIds. Изменение библиотечной карты делает её закрепление устаревшим. Ещё один fixture переносит карту обычным Git и привязки задач через sync в независимые clones, проверяя отсутствие подробного текста в Git общего workspace.

Smoke установленного пакета создаёт и коммитит источники и карту, обращается к новым операциям HTTP API и запускает CLI с `--require-complete`. Релиз без задач возвращает неполноту и exit 1.

## Границы проверки

coverageComplete проверяет цепочку для объявленных источников и выбранного релиза. Необъявленный файл и смысловую достаточность критериев/тестов проверяет ведущий агент и reviewer. Это не замена приёмке доски, совместному ChangeSet или разрешению публикации. Историческое evidence не доказывает работоспособность новой комбинации версий компонентов.

Формат — собственный профиль DevContour; автоматическая совместимость с любым свободным INTENT.md не заявляется. Семантическую нормализацию документа выполняет агент. Fixture-исполнитель проверяет протокол и Git-процесс, а не качество ответа реальной модели. Live-модели и корпоративная инфраструктура в этот прогон не входят.

Использование и ограничения: [продуктовое намерение](intent.md).
