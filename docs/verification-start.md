# Проверка явного выбора workspace

Дата: 17 сентября 2026. Среда: Node 24.3.0, macOS ARM64. Изменения проверены в отдельной копии инструмента, без вызовов моделей и без изменения продуктов пользователя.

## Поведение

- AGENTS.md, CLAUDE.md и START.md требуют от ведущего агента спросить абсолютный путь workspace в начале новой продуктовой сессии, если пользователь ещё не передал его. До ответа setup, задачи и сервер не запускаются. Продолжение с уже указанным путём не требует нового вопроса. Изменение исходников самого инструмента исключено из этого правила.
- CLI требует явный контекст команд разработки. `--workspace` выбирает `.harness/local` внутри указанной папки; `--data` сохраняет совместимость со старыми конфигурациями. Противоречивые/неполные флаги отклоняются. Workspace внутри каталога инструмента запрещён.
- `setup --workspace` сохраняет конфигурацию в выбранной внешней папке и закрепляет workspaceRoot. Повторный setup не перезаписывает настройки.
- Запуск без контекста завершается до создания demo. Учебный режим доступен через явный `demo`; npm run dev явно запускает demo с Vite.
- API сообщает dataRoot и workspaceRoot для проверки принадлежности сервера. Общего переключателя текущего проекта нет.

## Проверки

`npm run check`: token lint, typecheck и production build прошли. Все 45 unit/integration тестов прошли, включая настоящие Git/worktree сценарии прежнего ядра и новые проверки:

1. Отсутствующий, относительный, повторяющийся или противоречивый контекст отклоняется.
2. Голый serve ничего не создаёт в пустой папке.
3. Два отдельных CLI-процесса параллельно импортируют планы в разные workspace; каждый export содержит только свой проект.
4. Повторный setup сохраняет конфигурацию; workspace внутри продукта отклоняется до переноса правил.
5. Два HTTP-сервера одновременно слушают разные порты и возвращают собственные доски и пути.

Первый HTTP-запуск был остановлен песочницей с listen EPERM; после выдачи сетевого разрешения проверка была повторена успешно. Финальный format:check прошёл. Vite сохранил предупреждение о размере bundle.

Playwright: 1 HTTP E2E прошёл; 3 браузерных сценария остановились на запуске Chromium с MachPortRendezvousServer / Permission denied (1100). UI в этом изменении не модифицировался. Полный npm run check не считается зелёным: браузерную часть необходимо повторить в среде, разрешающей запуск Chromium. Тесты не отключались и не заменялись skip.

Диалог ведущего агента задан инструкциями; автоматизированные тесты не доказывают соблюдение этих инструкций любой моделью. Техническая защита CLI проверена фактическими отдельными процессами. Выбор свободного порта остаётся действием ведущего агента, автоматического распределения ресурсов между workspace нет.
