## Сбой heartbeat сохранён, а не скрыт повтором

В одном общем прогоне интеграционный сценарий потерял heartbeat дольше lease=30 секунд. Задача получила failed/expired и не была принята. В тот же период прервался bootstrap отдельного demo instance по той же причине. Источник паузы среды не установлен. Это проверка того, что просроченная попытка не может выдать запоздалый результат; одновременно это наблюдавшийся сбой стабильности длинного запуска, который нужно учитывать в пилоте.

Изолированный повтор того же Git-сценария без изменения теста или увеличения lease прошёл за ~21 секунду. Первичный результат остаётся FAIL в журнале. Поэтому этот отчёт **не утверждает, что полный npm run check был зелёным**.

- [Первичный общий прогон](../evidence/unit-integration-first-run.log)
- [Изолированный повтор](../evidence/pipeline-recheck.log)

Для ноутбука сон/длительная остановка процесса означают потерю владения и явный retry. Не увеличивайте lease, чтобы замаскировать сбой; настройте его по реальному окружению и проверьте восстановление. Если начальная генерация demo прервана до появления config.json, сохраните данные для разбора и выберите новый `--data`, не перезаписывайте повреждённый каталог.

## Браузерная проверка

Оболочка не разрешила запуск Chromium: `bootstrap_check_in ... Permission denied (1100)`. Ограничение не обходилось ослаблением sandbox. Для проверки UI использован штатный Chrome DevTools MCP. Действия выполнялись через формы и кнопки, сохранение результатов дополнительно сверялось через read-only API.

На доске «Каталог продуктов» выполнены r1 и r2. Корректировка корневой задачи создала пять новых задач; старые остались done. Digest снимка r1 до и после совпал: `347f43d112498aaa37d08ac742ef79f7d1b7911230676e652b2e26a66c56bd52`.

В CI и обычной локальной среде нужно выполнить `npx playwright install chromium && npm run check`. Скрипт не делает автоматический skip при отсутствии браузера. Четыре сценария Playwright сохранены в e2e/harness.spec.ts; воспроизводимый зелёный запуск этого runner здесь не заявляется.

## Неблокирующие замечания сборки

Vite сообщил о JavaScript chunk ~522 kB / ~161 kB gzip, в основном рабочий UI с React Flow. Code splitting — разумная следующая оптимизация. Node 24.3 выдаёт предупреждение об экспериментальном node:sqlite. Для командного развёртывания закрепите runtime и проверьте целевую версию Node.

MVP готов для локального пилота. До реальной автономной разработки нужны live-provider smoke test, тесты конкретного проекта и проверка длительной работы на выбранном хосте. Федерация, серверная merge queue и production-деплой в этой версии не реализованы.
