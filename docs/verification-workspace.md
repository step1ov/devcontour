# Проверка расширения workspace

Дата: 16 сентября 2026. Среда: Node 24.3.0, macOS ARM64. Реализация проверялась в изолированной копии шаблона. Продукт и библиотека в тестах — временные настоящие Git-репозитории; модель заменена явно обозначенным детерминированным adapter. Вызовов платных моделей и изменений пользовательских продуктов не было.

## Что проверено

- `npm run check`: token lint и production build прошли; **40/40** unit/integration тестов прошли. В этот запуск входят прежние сценарии одиночного репозитория и пять новых workspace-сценариев. Полная команда завершилась ошибкой на браузерной части, см. ниже.
- После уточнения журнала и HTTP проверок: **7/7** целевых тестов прошли, включая новый тест совместимости со старой БД. После добавления переноса workspace-инструкции и настройки concurrency: **11/11** тестов setup/workspace прошли. В итоговом наборе 41 уникальный unit/integration тест; после последних небольших изменений повторялись затронутые группы, а не весь набор.
- Финальные `typecheck`, `format:check`, token lint прошли. UI после исправления узкой раскладки повторно собран. Vite сообщает предупреждение о размере основного bundle; это не ошибка сборки.
- Межрепозиторный DAG: изменение библиотеки → задача продукта, собственные gates и integration refs, исходные checkout не изменены.
- Оба компонента проходят локальные тесты, но несовместимы вместе: реальный интеграционный сценарий завершается FAIL, приёмка ChangeSet отклонена. После отдельного исправления продукта совместный тест проходит на новых SHA.
- Manifest фиксирует SHA/tree обоих компонентов, evidence сохраняет hash артефакта. Попытка изменить manifest или tracked-файл другого компонента отклоняется.
- Второй controller не может занять тот же Git-репозиторий; повторная регистрация общего Git через alias тоже отклоняется.
- Lease/fencing запрещает поздний результат, совместная проверка блокирует новые claims, неполное evidence не даёт принять ChangeSet, изменённая политика требует новой проверки.
- Режим operator возвращает ожидание; agent принимает проверенный результат. Корректировка доски и следующий ChangeSet не изменяют принятую запись и её Markdown-дневник.
- Сбой записи проекции не откатывает уже сохранённые задачи/события. Старое однорепозиторное состояние получает repositoryId=main без изменения approvedDigest.
- HTTP API позволяет создать ChangeSet и получить дневник; запрещает приёмку/проверку без prerequisites и загрузку произвольного PASS.

## Браузер

Playwright: **1 HTTP E2E прошёл; 3 браузерных сценария не выполнились**, поскольку Chromium падает на старте с `MachPortRendezvousServer: Permission denied (1100)`. Обязательные тесты не отключались и не превращались в skip. Полный `npm run check` в этой среде не зелёный; его нужно повторить на машине/CI, где Playwright разрешён.

Дополнительно через Chrome DevTools MCP проверен новый интерфейс на настоящем двухрепозиторном fixture:

- Открытие общего графа: два узла, одна межрепозиторная связь. Фильтр library оставляет один соответствующий узел.
- Вкладка «Изменения» показывает manifest и успешный JUnit; кнопка приёмки сохраняет receipt с actor=operator.
- Открывается автоматически сформированный дневник с задачами, SHA, тестом, артефактом и приёмкой.
- Форма создаёт следующий ChangeSet со ссылкой supersedes на принятый; кнопка «Проверить совместно» запускает runner, который доходит до passed.
- На ширине 500 px обнаружено переполнение вкладок; после исправления scrollWidth равен innerWidth. Проверка axe (WCAG 2A/2AA/2.1AA) для экрана изменений и общего графа: 0 нарушений. Десктопный экран проверен при 1440 px.

Это дополнительная проверка UI, а не замена всех невыполненных Playwright-сценариев. Ширина 390 px не заявляется: доступный desktop Chrome ограничивает минимальный размер окна.

## Не проверялось в этом запуске

Live Claude/Codex review, реальные библиотеки пользователя, публикация пакетов, deployment, мобильный Maestro, несколько OS-хостов и полноценный sandbox. Интеграционный скрипт каждого продукта требуется подготовить так, чтобы он действительно подключал закреплённую библиотеку; runner сам не определяет семантику package manager. Федерация независимых workspace и атомарный merge нескольких Git-репозиториев не реализованы.
