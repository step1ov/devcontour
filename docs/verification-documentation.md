## Браузерный сценарий

В отдельном demo data root выполнены запуск очереди, пять задач до локальной интеграции, открытие evidence, приёмка r1, расчёт влияния изменения API и создание r2. В истории одновременно отображаются принятая r1 и активная r2. Сняты граф, список с проверками, диалог корректировки, история и мобильный список.

Desktop viewport: 1600×1100, mobile viewport: 390×844; mobile PNG содержит полную страницу высотой 2418 px. Горизонтального переполнения документа на этих размерах не обнаружено. Изображения просмотрены, подписи соответствуют фактическому состоянию.

Это ручной сценарий через Chrome DevTools на учебных данных, не полный повтор Playwright suite и не live-тест моделей. Полный `npm run check` в рамках документационного изменения не заявляется как выполненный. Ранее известное ограничение запуска Playwright Chromium описано в [отчёте переименования](verification-rename.md). Код UI в этом изменении не менялся.

Live Codex/Claude, корпоративный MCP, реальные registry/устройства/Postgres/forge здесь не проверялись. Существующие интеграционные fixtures доказывают локальные механизмы и условия отказа, а не готовность конкретной внешней среды.
