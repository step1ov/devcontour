# Переименование в DevContour

Дата: 2026-09-17.

Проект и npm package получили имя `devcontour`. Основная команда — `npm run devcontour -- <команда>`. Обновлены заголовок страницы, логотип/подписи интерфейса, CLI help, стартовые инструкции, активная документация, переносимые правила, название CI и модуль PhpStorm. Каталог проекта — `/Users/antonstepanov/PhpstormProjects/devcontour` вместе с установленными зависимостями и настройками IDE.

Прямой rename исходного каталога был отклонён файловой песочницей (`Operation not permitted`) и после разрешения доступа к родительскому каталогу. Поэтому новый каталог развёрнут копированием; исходный `harness-template` сохранён как резервная копия, дальнейшая работа ведётся в `devcontour`.

## Совместимость

`npm run harness` — сохранённый алиас той же команды. Сравнение вывода help подтвердило одинаковое поведение обоих входов.

Формат SQLite, schemas, state machine и закреплённые стековые профили сверены по SHA-256 с версией до переименования: изменений нет. Служебные `.harness/`, `harness.component.json`, refs `harness/*`, переменные `HARNESS_*`, `test:harness`, HTTP header и имена уже устанавливаемых документов сохраняются. Переименование инструмента не требует перемещения продуктовых workspace или миграции их баз.

Исторические исследования, логи и отчёты сохраняют название на момент их создания. Текущие инструкции используют DevContour.
