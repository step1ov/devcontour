# Переименование в DevContour

Дата: 2026-09-17.

Проект и npm package получили имя `devcontour`. Основная команда — `npm run devcontour -- <команда>`. Обновлены заголовок страницы, логотип/подписи интерфейса, CLI help, стартовые инструкции, активная документация, переносимые правила, название CI и модуль PhpStorm. Каталог проекта — `<checkout>/devcontour` вместе с установленными зависимостями и настройками IDE.

## Текущее состояние

Первое переименование касалось бренда. 2026-09-18 завершён разрыв со старым служебным именем: каталог локального состояния — `.devcontour-local/`, конфигурация компонента — `devcontour.component.json`, refs — `devcontour/*`, переменные — `DEVCONTOUR_*`, HTTP header — `X-DevContour-Request`. Устанавливаемые документы используют префикс `devcontour-`. Внутренний сервис называется `DevContour`. Алиас старой npm-команды удалён.

Переносимая память `.devcontour/` остаётся в Git; `.devcontour-local/` исключается из Git. Старые пути, заголовки и refs не распознаются, автоматической миграции экспериментальных workspace нет. Создайте новую конфигурацию через setup и перенесите только проверенные исходники и документы. Старые данные сохраняйте отдельно; переименование не выдаёт прежние evidence за проверки новой политики.

Ниже сохранены результаты первого этапа. Логи в evidence — исторические, с обезличенными путями; старые имена внутри них не являются поддерживаемыми интерфейсами.
