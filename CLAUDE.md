# Работа с DevContour

Сначала прочитай и соблюдай [AGENTS.md](AGENTS.md). Для разработки продукта следуй [START.md](START.md).

Если пользователь ещё не указал workspace этой продуктовой сессии, спроси: «В какой папке вести workspace этого проекта? Укажите абсолютный путь». Дождись ответа до setup, создания задач и запуска сервера. Уже указанный путь используй без повторного вопроса. При изменении самого инструмента продуктовый workspace не требуется.

Каждая независимая продуктовая сессия использует свой workspace и порт. Не сохраняй продуктовую память и глобальный active-workspace в общем devcontour. После выбора пути остальные обычные этапы агент выполняет самостоятельно по approvalMode.
